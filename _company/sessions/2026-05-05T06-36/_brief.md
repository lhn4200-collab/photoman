# 📋 작업 브리프

**원 명령:** 와이어프레임 제작을 진행해줘

## 요약
Starter Kit (A)의 판매를 위한 전용 랜딩 페이지 와이어프레임을 제작하는 것이 목표입니다. 이 페이지는 단순한 웹사이트가 아니라, 잠재 고객을 '구매'로 이끌어내는 고도의 컨버전스 장치여야 합니다.

## 분배
- **💰 Business**: 랜딩 페이지의 목표(KPI: Starter Kit (A) 판매 전환율 극대화)를 재정의하고, 필수적인 고객 구매 여정(Buyer Journey) 기반의 섹션 구성을 정의해 주세요. (예: 히어로 섹션 → 문제 제기(Pain Point) → 솔루션 제시(제품 소개) → 신뢰 구축(후기/자격) → CTA/가격 책정). 각 섹션별로 어떤 내용이 들어가야 하는지 논리적 순서와 역할을 정의합니다.
- **🎨 Designer**: Business가 정의한 섹션 구성을 바탕으로, 반응형 웹 환경(모바일 우선)의 와이어프레임 디자인 브리프를 작성해 주세요. 시각적 계층 구조(Visual Hierarchy)가 명확해야 하며, 사용자가 스크롤하며 자연스럽게 제품의 가치를 인지하고 구매 버튼(CTA)에 도달하도록 유도하는 레이아웃(Layout)을 중점적으로 제시해 주세요. 핵심적인 브랜드 색상과 타이포그래피 톤을 반영해야 합니다.
- **💻 Developer**: Business와 Designer가 확정한 와이어프레임 구조와 브리프를 기반으로, 실제 구현 가능한 와이어프레임 코드를 작성해 주세요. (HTML/CSS 구조 정의 및 주요 컴포넌트(Hero, Pricing Block, Testimonial Carousel)의 구조적 뼈대 설계). 결제 시스템 연동을 위한 API Placeholder와 데이터 파이프라인 연결 지점도 함께 명시해야 합니다.
